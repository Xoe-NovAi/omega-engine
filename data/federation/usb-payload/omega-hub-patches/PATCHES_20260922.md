## Patch 1: Remove deprecated `library_search` tool
**File:** `mcp_servers/omega_hub/server.py`
**Change:** Added `mcp.remove_tool("library_search")` after tool registration (side-effect import).
**Rationale:** `library_search` was a legacy hybrid-search name that misleadingly suggested local search while hitting the web pipeline. Superseded by:
- `library_fts_search` — local FTS5 search
- `library_web_search` — web search (Sovereign Search pipeline)

**Effect:** Tool surface 93 → 92. `library_search` no longer appears in `tools/list` and cannot be called.

## Patch 3: Fix `omega_federation_status` direct-connection detection
**File:** `mcp_servers/omega_hub/hub_tools/federation.py`
**Change:** `_peer_is_direct()` now probes idle peers with `tailscale ping` when `CurAddr` is empty.
**Rationale:** `tailscale status --json` returns empty `CurAddr` for idle peers even when a direct path exists. The old logic misreported healthy LAN peers as DERP-relayed (the "relay mia" false alarm).
