## §1 The Lattice Axes

The Lattice Mesh is defined by three primary axes. Every research finding is mapped to at least one coordinate on each axis.

### Axis X: The Technical $\leftrightarrow$ Philosophical
- **Technical (0.0)**: Implementation details, API specs, code patterns, performance metrics. (The "How")
- **Philosophical (1.0)**: First principles, architectural intent, sovereign mandates, timeless truths. (The "Why")

### Axis Y: The Historical $\leftrightarrow$ Future
- **Historical (0.0)**: Legacy patterns, id Software heritage, previous versions, "how we got here". (The "Was")
- **Future (1.0)**: Roadmap, evolution targets, predicted bottlenecks, "where we are going". (The "Will Be")

### Axis Z: The Practical $\leftrightarrow$ Theoretical
- **Practical (0.0)**: Working prototypes, bug fixes, CLI commands, "what actually works". (The "Is")
- **Theoretical (1.0)**: Formal specifications, mathematical models, conceptual frameworks. (The "Could Be")
