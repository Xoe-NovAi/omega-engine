## §2 Fleet Operating Model

**There was no automated coordination.** The fleet was manually operated:

1. **Workspace/Projects Feature**: Grok's built-in "Project" system allowed per-workspace system prompts and file uploads. The user set up different workspaces with different system prompts for:
   - **Grok MC-Arcana** (on XNA-MAYBE) — Strategic overseer with memory of the full stack
   - **Dev/Coding Expert** (on Antipode2727) — Focused on code generation and review
   - **Hacking Research** (on TJF, later Antipode2727) — Security research workspace
   - **ML Research** (on LA) — Deep research into ML topics
   - **Docker/Stack** (on ArcanaNovai) — Infrastructure development

2. **Manual Account Switching**: The user would:
   - Hit rate limit on one account → switch to another
   - Need a different persona → switch to the account with that workspace
   - Continue a conversation from a different angle → open on another account

3. **Cross-Account Continuations**: 14 detected cross-account references with an average 2–10 hour gap. This is confirmed account rotation — not parallel use.
