### W3: Kerykeion / pyswisseph — versions, license, footprint ✅ RESOLVED (with hazard)

- **Kerykeion v5.12.9** (stable): AGPL-3.0, Python ≥3.10, deps incl. pyswisseph ≥2.10.3.2, pydantic ≥2.5. **v6.0.0a26 alpha**: Python ≥3.12, adds libephemeris backend option.
- **🚨 LICENSING HAZARD for OQ-009**: AGPL-3.0 is viral — linking Kerykeion into Omega Engine (Apache-2.0 WAD) would obligate AGPL compliance on the linked work. Options for N3 ruling: (a) `[astrology]` extra as optional, non-default dependency with documented AGPL boundary; (b) use **pyswisseph directly** (GPL-2.0+, process-boundary via subprocess keeps engine clean); (c) hosted Astrologer API (external service — violates M7 local-first spirit). Recommend (b) for engine core, (a) for optional extras.
- **Footprint**: pyswisseph is a C-extension binding (~few MB, CPU-only, no GPU); Swiss Ephemeris data files add ~50MB for full precision. Acceptable on 14Gi host per N11 serial-load constraint.
