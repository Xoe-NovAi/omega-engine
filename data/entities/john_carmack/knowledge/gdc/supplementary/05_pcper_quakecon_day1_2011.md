# PC Perspective — QuakeCon 2011 Day 1 Coverage
**Source**: https://pcper.com/2011/08/quakecon-2011-day-1-coverage/2/
**Author**: Steve Grever, Josh Walrath

Key points not covered elsewhere:

- Carmack "does not work from a script or slides" — free-form diatribe
- Code verification: "Any code base is becoming simply huge, and simple mistakes that would not show themselves when written, but become show stoppers when the scope of the program exceeds the limitations of that poorly written code."
- Bethesda Legal not opposed to GPL source releases; patent concerns remain but "until these fears actually manifest themselves, id will continue to release the source code under the GPL"
- OpenCL and GPGPU "not of great interest" — prefers using multiple cores on x86 and ARM
- VOXEL ENGINES: Carmack has "written several voxel based engines over the years, often right after some of their major gaming releases." Feels current hardware still makes voxels inferior to polygon/raster. "In the end ray tracing will win out" but animations, deformations, skeletal systems not ready.
- Android porting "put on hold" — "do not expect games to be available on Android anytime soon"
