# QuakeCon 2011 Keynote — Alejandro Segovia Azapian Summary
**Source**: https://www.alejandrosegovia.net/2011/08/08/quakecon-2011-keynote/

Concise technical summary:

1. **Megatexturing/id Tech 5**: Implementation details of engine powering Rage
2. **Cross-platform issues**: PC, Xbox 360, PS3 — maintaining steady 60fps while managing huge datasets
3. **Static analysis tools**: "Microsoft Analyse", "PVS Studio", "PC lint" for finding bugs in large codebases
4. **Anti-scripting**: Script interpreters are hard to debug, impact performance. Recommends Java-like subset of C++ — strict typing, restrictive language, find bugs "as early as possible" at compile time
5. **Doom 3 source**: Announces release later in 2011, recommends buying a copy from Steam
6. **Development costs**: Compare "early days" with modern process — unsustainable scaling
