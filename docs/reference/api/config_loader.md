## Overview

The `omega.config` package implements the **R19 Part 3 Gitignored Config Split**. It provides a `ConfigLoader` that deep-merges public (git-tracked) configuration with private (gitignored, encrypted) configuration at runtime.

This prevents API keys, secrets, and machine-specific configuration from leaking into version control while keeping the public configuration schema navigable.

### Key Methods

#### `load(namespace: str, fallback: Optional[dict] = None) -> dict`
Load a config namespace, merging public + private with private taking precedence.

- `namespace`: Config name (e.g. `"omega"`, `"providers"`)
- `fallback`: Default data if no public config found
- Returns: Merged dict (private values override public)
- **Cached**: Subsequent calls return cached result

#### `load_providers() -> dict`
Convenience: Load `providers.public.yaml` + `providers.private.yaml` merged.

- Returns: Unified provider config with endpoints from public, keys from private

#### `ensure_private_dirs() -> None`
Create `config/private/` + `.gitignore` if they don't exist.

- Idempotent: Safe to call on every startup
- Creates `.gitignore` with `private/` exclusion pattern

#### `write_private(namespace: str, data: dict) -> None`
Write to private config (e.g., save updated API keys).

- Encrypts if `auto_decrypt=True` and vault crypto available
- Merges with existing private data

#### `clear_cache(namespace: Optional[str] = None) -> None`
Clear config cache (all or specific namespace).

#### `get_private_path(namespace: str) -> Path`
Get the path to a private config namespace.

## Deep Merge Rules

1. Public config is loaded first (git-tracked schema)
2. Private config is loaded second (gitignored secrets)
3. Private values **override** public values at same key path
4. Dicts are merged recursively (scalar values replaced)
5. Lists are **replaced**, not merged (to prevent duplicate entries)

```yaml
# config/public/providers.yaml
providers:
  groq:
    endpoint: "https://api.groq.com/openai/v1"
    model: "llama-3.3-70b"
    rate_limit: 30

# config/private/providers.yaml  
providers:
  groq:
    api_key: "gsk_..."  # Only in private
    rate_limit: 60       # Overrides public

# Result (merged):
providers:
  groq:
    endpoint: "https://api.groq.com/openai/v1"  # From public
    model: "llama-3.3-70b"                       # From public
    api_key: "gsk_..."                            # From private
    rate_limit: 60                                # Private overrides public
```

## .gitignore Template

When `ensure_private_dirs()` is called, it generates:

```gitignore
# Omega Engine — Private Config (auto-generated)
# DO NOT EDIT — regenerated by ConfigLoader.ensure_private_dirs()

# Ignore all private config directories
private/
```

This ensures `config/private/` is never tracked by git.

## Usage

### Basic Initialization
```python
from omega.config import ConfigLoader

loader = ConfigLoader("config")
loader.ensure_private_dirs()  # First run: creates private/ + .gitignore

# Load merged provider config
providers = loader.load_providers()
groq_key = providers["groq"]["api_key"]  # From private config
groq_endpoint = providers["groq"]["endpoint"]  # From public config
```

### Writing Private Config
```python
# Save a new API key
loader.write_private("providers", {
    "providers": {
        "cerebras": {"api_key": "c94_..."},
        "groq": {"api_key": "gsk_..."}
    }
})
```

### Provider Config Model
```python
from omega.config.loader import ProviderConfig

# ProviderConfig is a TypedDict with fields:
# - name: str
# - endpoint: str
# - api_key: str (from private config)
```
