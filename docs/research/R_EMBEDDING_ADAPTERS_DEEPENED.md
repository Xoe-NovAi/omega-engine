## 🛡️ Technical Specification

### 1. Current Architecture — The MD5 Feature Hash Bottleneck

The engine has **4 independent implementations** of the same bag-of-words embedding algorithm:

| File | Line | Purpose |
|------|------|---------|
| `src/omega/memory/embeddings.py` | 60-79 | `SovereignFallbackEmbeddingProvider.get_embedding()` — primary provider chain |
| `src/omega/memory_store.py` | 305-347 | `_compute_simple_embedding()` — legacy duplicate |
| `src/omega/library/indexer.py` | 346-369 | `_compute_embedding()` — library indexer path |
| `src/omega/library/crossref.py` | 65-85 | `_compute_embedding()` — cross-reference path |

**Mechanism**: Each splits text on whitespace/regex → strips ~80 stopwords → hashes each token with `hashlib.md5(token.encode())` → maps to 0-255 via modulo → sums into a 256-dim bag vector → L2-normalizes.

**Why this fails for semantic search**:
- No word order preserved → "dog bites man" ≈ "man bites dog"
- No synonym handling → "car" ≠ "automobile" in vector space
- No subword understanding → "embedding" ≠ "embed" ≠ "embedded"
- 256-dim at float32 = 1KB per vector — but zero semantic signal density

**Qdrant currently stores 653 vectors generated by this algorithm**. Their semantic retrieval quality is poor — the adapter infrastructure is production-ready, the vectors are not.

### 2. The Embedding Provider Chain (Existing Interface)

`src/omega/memory/embeddings.py` already defines the correct abstraction:

```python
class IEmbeddingProvider(ABC):
    @abstractmethod
    async def get_embedding(self, text: str) -> List[float]: ...

    @property
    @abstractmethod
    def dimension(self) -> int: ...

class EmbeddingManager:
    """Tries providers in order; falls through on failure."""
    def __init__(self, providers: List[IEmbeddingProvider]): ...

    async def get_embedding(self, text: str) -> List[float]:
        for provider in self._providers:
            try:
                return await provider.get_embedding(text)
            except Exception:
                continue
        raise RuntimeError("All embedding providers failed")
```

**Strategy**: Insert a `SovereignMLXEmbeddingProvider` as the **first** provider in the chain, keeping `SovereignFallbackEmbeddingProvider` as the last-resort fallback. The `IEmbeddingProvider` interface requires zero changes to the rest of the memory/routing stack.

#### Quantization Strategy for Embeddings

Based on CrispEmbed's comprehensive benchmark (28 models verified, cos >= 0.965 vs HF):

| Quant | Compression | Quality (cos vs F32) | Recommended For |
|-------|-------------|---------------------|-----------------|
| F32 | 1x | 1.0 (baseline) | Reference, batch inference |
| Q8_0 | ~3.8x | > 0.995 | **Default** — near-lossless, fast on CPU |
| Q5_K | ~5x | > 0.98 | Good balance if space-constrained |

class OllamaEmbeddingProvider(IEmbeddingProvider):
    """Embedding via Ollama's /api/embed endpoint."""
    
    def __init__(self, model: str = "nomic-embed-text", base_url: str = "http://localhost:11434"):
        self._model = model
        self._base_url = base_url.rstrip("/")
        self._dim = self._detect_dimension()
    
    def _detect_dimension(self) -> int:
        import httpx
        resp = httpx.post(f"{self._base_url}/api/embed", json={
            "model": self._model,
            "input": "dimension probe"
        }, timeout=10)
        resp.raise_for_status()
        return len(resp.json()["embeddings"][0])
    
    @property
    def dimension(self) -> int:
        return self._dim
    
    async def get_embedding(self, text: str) -> List[float]:
        import httpx
        # [id-soft: quake-1996] Grace Period — 0.5s timeout for fast retrieval
        async with httpx.AsyncClient(timeout=30) as client:
            resp = await client.post(f"{self._base_url}/api/embed", json={
                "model": self._model,
                "input": text,
                "options": {"num_ctx": 8192}  # Full context window
            })
            resp.raise_for_status()
            return resp.json()["embeddings"][0]

#### Path C: ONNX Runtime (CPU-optimized)

ONNX Runtime provides CPU-optimized inference with quantization support:

```python
class ONNXEmbeddingProvider(IEmbeddingProvider):
    """ONNX Runtime embedding for CPU-optimized inference."""
    
    def __init__(self, model_path: str, tokenizer_path: str):
        import onnxruntime as ort
        from transformers import AutoTokenizer
        
        self._session = ort.InferenceSession(
            model_path,
            providers=["CPUExecutionProvider"]
        )
        self._tokenizer = AutoTokenizer.from_pretrained(tokenizer_path)
        self._dim = self._session.get_outputs()[0].shape[-1]  # 384 for MiniLM
    
    @property
    def dimension(self) -> int:
        return self._dim
    
    async def get_embedding(self, text: str) -> List[float]:
        import anyio
        import numpy as np
        
        def _encode():
            inputs = self._tokenizer(
                text, padding=True, truncation=True, max_length=256,
                return_tensors="np"
            )
            outputs = self._session.run(
                ["sentence_embedding"],
                {"input_ids": inputs["input_ids"], "attention_mask": inputs["attention_mask"]}
            )
            return outputs[0][0].tolist()
        
        return await anyio.to_thread.run_sync(_encode)
```

**Intel IPEX optimization**: Intel's Optimum Intel with IPEX and INT8 quantization can achieve up to 4.5x speedup on BGE models. Requires `intel-extension-for-pytorch` and `optimum-intel`. See Hugging Face blog: "CPU Optimized Embeddings with Optimum Intel and fastRAG" (2024).

#### Orthogonal Procrustes Implementation

```python
class OrthogonalProcrustesAdapter:
    """Adapter that maps embeddings from one model's space to another.
    
    [id-soft: quake3-1999] netchan Protocol — maps between vector "address spaces"
    via learned rotation matrix.
    """
    
    def __init__(self, source_dim: int, target_dim: int):
        self._W: Optional[np.ndarray] = None  # Rotation matrix
        self._source_dim = source_dim
        self._target_dim = target_dim
    
    def fit(self, X_source: np.ndarray, X_target: np.ndarray) -> None:
        """Compute optimal orthogonal mapping between embedding spaces.
        
        Args:
            X_source: (n_samples, source_dim) — embeddings from source model
            X_target: (n_samples, target_dim) — embeddings from target model
                      for the SAME texts
        """
        # Handle dimensional mismatch via padding or SVD projection
        if self._source_dim != self._target_dim:
            X_source = self._project_to_target_dim(X_source)
        
        # Orthogonal Procrustes: M = X^T Y, then W = U V^T from SVD(M)
        M = X_source.T @ X_target
        U, _, Vt = np.linalg.svd(M, full_matrices=False)
        self._W = U @ Vt  # Optimal rotation matrix
        self._fitted = True
    
    def transform(self, X: np.ndarray) -> np.ndarray:
        """Apply the learned rotation to new embeddings."""
        if not self._fitted:
            raise RuntimeError("Adapter not fitted. Call fit() first.")
        if self._source_dim != self._target_dim:
            X = self._project_to_target_dim(X)
        return X @ self._W
    
    def _project_to_target_dim(self, X: np.ndarray) -> np.ndarray:
        """SVD projection for cross-dimensional mapping."""
        if X.shape[1] < self._target_dim:
            # Pad: smaller → larger (preserve original geometry)
            padded = np.zeros((X.shape[0], self._target_dim))
            padded[:, :X.shape[1]] = X
            return padded
        else:
            # SVD project: larger → smaller
            U, S, Vt = np.linalg.svd(X, full_matrices=False)
            return X @ Vt[:self._target_dim].T
```

**CKA Validation Gate**:

```python
def centered_kernel_alignment(X: np.ndarray, Y: np.ndarray) -> float:
    """Compute CKA between two embedding spaces.
    
    Decision gate:
        CKA > 0.9  → Near-lossless adaptation (Procrustes sufficient)
        0.8-0.9    → Viable; expect minor recall drop
        < 0.8      → Full re-indexing required
    """
    def hsic(K, L):
        n = K.shape[0]
        H = np.eye(n) - np.ones((n, n)) / n
        K_c = H @ K @ H
        L_c = H @ L @ H
        return np.sum(K_c * L_c) / (n - 1)**2
    
    K = X @ X.T  # Linear kernel
    L = Y @ Y.T
    return hsic(K, L) / np.sqrt(hsic(K, K) * hsic(L, L))
```

**Calibration corpus**: ~5,000 sentence pairs from the same texts embedded by both models. ~10MB of storage for both embedding sets. Single SVD computation (< 1 second for 5K × 768).

| Mode | Cause | Detection | Recovery |
|------|-------|-----------|----------|
