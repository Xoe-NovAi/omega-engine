```typescript
// Detection: regex match on model ID
function isGemma4Model(model: Model<"google-generative-ai">): boolean {
  return /gemma-?4/.test(model.id.toLowerCase());
}

// Routing: Gemma 4 uses thinkingLevel path (same as Gemini 3)
if (isGemini3ProModel(googleModel) || isGemini3FlashModel(googleModel) || isGemma4Model(googleModel)) {
  return streamGoogle(model, context, {
    ...base,
    thinking: {
      enabled: true,
      level: getThinkingLevel(effort, googleModel),
    },
  } satisfies GoogleOptions);
}

// Thinking level mapping: Pi levels → Gemma 4 binary levels
function getThinkingLevel(effort: ClampedThinkingLevel, model: Model<"google-generative-ai">): GoogleThinkingLevel {
  if (isGemma4Model(model)) {
    switch (effort) {
      case "minimal":
      case "low":
        return "MINIMAL";
      case "medium":
      case "high":
        return "HIGH";
    }
  }
  // ... Gemini 3 logic
}

// Disabled thinking config for Gemma 4
function getDisabledThinkingConfig(model: Model<"google-generative-ai">): ThinkingConfig {
  if (isGemma4Model(model)) {
    return { thinkingLevel: "MINIMAL" as any };
  }
  // ... Gemini 2.x uses thinkingBudget: 0
}
```

## 🎯 Implementation Guidance for Omega Engine

### Required in `google_compat.py`:
1. **Detection**: `re.search(r'gemma-?4', model_id, re.IGNORECASE)`
2. **Routing**: Use `thinkingConfig.thinkingLevel` (not `thinkingBudget`)
3. **Mapping**: 
   - `minimal`/`low` → `"MINIMAL"`
   - `medium`/`high` → `"HIGH"`
4. **Disable**: Send `thinkingConfig: { thinkingLevel: "MINIMAL" }` (not `thinkingBudget: 0`)

### OpenCode Bug Root Cause
OpenCode's `transform.ts` sends:
- Model ID: `google/gemma-4-31b-it` (wrong — should be `gemma-4-31b-it`)
- Thinking config: `thinkingBudget` (wrong — Gemma 4 uses `thinkingLevel`)
- Levels: `low`/`medium` (wrong — Gemma 4 only accepts `MINIMAL`/`HIGH`)

**Fix**: Update OpenCode's Google provider transform OR route Gemma 4 through Cline CLI (which works per discovery).
