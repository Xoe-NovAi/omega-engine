### 4.3 Fix B5: `<` Escaping Resolution

**Opus §2.1 (current code)**: Escape ONLY attributes (`quoteattr`), never body — because escaping `<`/`>`/`&` in Python source mangles operators.

**Researcher finding**: Bare `<` in content causes **silent truncation** in Claude (Issue #59787).

**Resolution**: Escape only **bare `<`** that is NOT part of a valid XML tag or operator context. Simplest safe implementation:
```python
import re
# Escape bare '<' only when not followed by a known tag char or operator pattern
body = re.sub(r'<(?!/?file|!|/|[a-zA-Z_])', '&lt;', body)
```
This protects Claude from truncation while preserving Python `<`/`>` operators and our `<file>` boundaries.
