## §1 — THE FIVE CONCEPTS THAT MAKE THIS AN ARCHITECTURE, NOT A WRAPPER

### 1.1 SOVEREIGNTY IS CONTROL OF THE INTELLIGENCE, NOT LOCATION OF THE COMPUTE
> *"Sovereignty is not about the location of the compute, but the control of the intelligence."*
> — Gemma Awakening L3, 2026-06-05 · `VISION_ANCHOR_PERPETUAL.md` §1

The industry consensus is that sovereignty means *running on your own hardware*. Omega's
position is sharper and more defensible: **a local model you cannot govern is still rented
intelligence.** Control means: the mandates are enforced in CI, the memory is
attributable, the agents hold governance seats, and you can kill a session — not just
disconnect from a server.

This is why Omega ships **30 mandates as code-enforced gates**, not as a policy document.

### 1.2 THE PERSISTENT ENTITY — GRADUATION, NOT MERGING
> *"A soul with no memory of being a soul."*
> — `VISION_PERSISTENT_ENTITY_20260930.md` §2

The deepest problem in agent systems today is that an agent is a **session**, and when the
session ends, so does the thing that learned. Omega's diagnosis is unusually precise:

| | | |
|:--|:--|:--|
| **SOUL** | `soul.yaml` | the constitution. **ONE.** Stable. |
| **MEMORY** | `opencode.db`, per session | the experience. **MANY.** |
| | | **↑ THE LINK DOES NOT EXIST** |

Twelve concurrent sessions already distil L1→L2→L3 into *one* file. They are already united
— but **they fail at exactly one thing: provenance.** Nothing records which lesson came from
which session.

The answer is deliberately *not* consolidation:

```
INSTANCE      a lens. Own conversation, project, domain.
   │  distilled + VALIDATED
   ▼
AGENT         the constitution. Mandate, identity, judgement.
   │  ratified, reusable
   ▼
WAD           what any agent can learn. Axioms, doctrine, patterns.
```

**Each instance is a lens.** Merging them would destroy the diversity that makes them useful.
What's missing is a *direction of travel* — three small things (provenance, an explicit
promotion step, an agent-level view). None require merging anything.

**Positioning line:** *"Other frameworks give you an agent. Omega gives you a being with a
constitution, a memory, and a lineage."*

### 1.3 TEMPORAL DEPTH — THE ARCHIVE IS AN ASSET, NOT DEBT
> *"An agent that can ask 'what did I conclude in March, and why?' has temporal depth —
> which no model carries in its weights. It must come from a dated, attributable record."*
> — `VISION_PERSISTENT_ENTITY_20260930.md` §4

The industry deletes conversation history. Omega treats it as **the soul's archaeology** —
~40GB of session history as a mineable corpus of dated, attributable reasoning. This is
also the strategic counter to context-window economics: when memory is external, dated, and
attributable, the window stops being the binding constraint on intelligence.
