## 2. Core Axioms

1. **Local as the Sovereign Floor, Cloud as the Accountable Extension:**
   Sovereignty-critical tasks (internal memory, ops, heartbeat, personal records) never leave the local silicon. When frontier cloud models are engaged for complex synthesis, they are treated as capability extensions with mandatory provider provenance logging—never as silent defaults.

2. **The Engine / WAD Separation (The Doom Paradigm):**
   - **The Engine (`DOOM.EXE`)**: Hardened, deterministic, AnyIO-pure runtime. It manages silicon scheduling, P-core pinning, memory indexes, and peer-to-peer transport.
   - **The WAD (`DOOM1.WAD` / `MODS.WAD`)**: Pure data, prompts, cognitive maps, 3D glTF scenes, and personality definitions (`soul.yaml`). The Engine speaks "slots"; the WAD speaks "archetypes".

3. **Constitutional Zero Telemetry (Mandate 8):**
   There are no tracking pixels, no phone-home analytics, and no background metrics sent to third parties. Deletions are permanent. Audit logs are local.

4. **Hardware Discipline (DHAL & Archangel):**
   The Dynamic Hardware Adaptation Layer (DHAL) probes silicon topology at runtime. Agents run under the Archangel system envelope, keeping them strictly aware of actual hardware reality (VRAM ceilings, thread counts, memory channels) to prevent hallucinated compute capabilities.
