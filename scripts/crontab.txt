# Omega Engine — Probe & Monitoring Crontab
# Date: 2026-08-27
# Author: maat (probe-report-actions-20260827)
# Authority: Architect GO via kali
#
# To install:
#   crontab scripts/crontab.txt
#   (or: crontab < scripts/crontab.txt)
#
# To verify:
#   crontab -l | grep probe_free_models
#
# Design rationale (per PROVIDER_RELIABILITY_REPORT_20260827.md):
#   - 00:00 UTC: fresh daily quota reset (best availability)
#   - 06:00 UTC: moderate (next best)
#   - 12:00 UTC: poor (quota partially consumed)
#   - 18:00 UTC: worst (quota exhausted by this time)
#   - 30-min interval: capture fine-grained transitions between quota windows
#   - 4 quota-window probes: aligned with reset + key milestones
#   - Percentile + alert: post-cycle, after each 30-min probe
#
# Schedule:
#   - Every 30 min: probe_free_models.sh
#   - Quota windows (00/06/12/18 UTC): full probe with explicit "window" tag
#   - 5 min after each probe: probe_percentiles.py (recompute)
#   - 6 min after each probe: alert_state_change.sh (diff + Hivemind post)
#   - Daily at 00:30 UTC: full state diff report (archived)

# --- Logrotate (existing) ---
0 3 * * * /usr/sbin/logrotate /home/arcana-novai/.config/logrotate/omega-hub --state /home/arcana-novai/.config/logrotate/omega-hub.state

# --- Probe: every 30 min ---
*/30 * * * * /home/arcana-novai/Documents/Xoe-NovAi/omega-engine/scripts/probe_free_models.sh >> /home/arcana-novai/Documents/Xoe-NovAi/omega-engine/data/metrics/free_model_probes.log 2>&1

# --- Probe: quota-window aligned (00, 06, 12, 18 UTC) — main workhorse run ---
# The every-30-min probe already covers these. These extra entries ensure the
# state-change detection has a fresh reading at the start of each window.
